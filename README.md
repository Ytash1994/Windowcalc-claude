# حاسبة الشبابيك

تطبيق لحساب مقاسات تصنيع الشبابيك والواجهات. تُدخل الطول والعرض الأصليين لكل شباك، فيحسب لك التطبيق مقاس كل قطعة (الحلق، الزجاج، المنخل، الصندوق، الكشفة وغيرها)، ثم تحفظ النتائج بصيغة **PDF** أو **Excel** أو تشاركها مباشرة. يعمل في المتصفح، ويمكن تحويله إلى تطبيق **أندرويد (APK)** تلقائياً عبر GitHub Actions.

> هذه نسخة معدّلة من مشروع AI Studio الأصلي (`NewwindowappAIstudio`). التعديلات مذكورة في قسم [التعديلات في هذه النسخة](#التعديلات-في-هذه-النسخة).

## المزايا

- **أربعة أنواع جاهزة** من الشبابيك، لكل نوع معادلاته وقطعه (انظر الجدول أدناه).
- **ثلاث خطوات واضحة:** النوع ← القياسات ← النتائج.
- **وحدات القياس:** متر، سنتيمتر، ملّيمتر. عند تغيير الوحدة تُحوَّل القياسات المدخلة تلقائياً.
- **عدد القطع لكل شباك** وأسماء اختيارية للشبابيك.
- **ملخّص الشبابيك المتشابهة:** يجمع الشبابيك ذات المقاس نفسه ويعرض أرقامها وعددها.
- **تنبيهات:** تحذير عند ظهور قياسات سالبة (شباك صغير جداً) وعند وجود قياسات غير صالحة.
- **عرض النتائج** كبطاقات أو كجدول، مع جمع مساحات الزجاج والشبابيك.
- **أنواع وخانات وعلاقات قابلة للتعديل:** يمكنك إضافة نوع خاص بك، وإضافة خانات جديدة، وتعديل علاقة أي خانة (مثل «الطول − رقم» أو «العرض ÷ 2»)، وإعدادات التقريب.
- **مشاريع محفوظة:** تُحفظ بأسمائها على الجهاز لتعود إليها لاحقاً.
- **استيراد من Excel** لملفات صدّرها التطبيق سابقاً (القياسات والإعدادات والعلاقات).
- **نسخة احتياطية** لأنواعك وعلاقاتك ومشاريعك بملف JSON.
- **أدوات سريعة:** لصق قياسات بصيغة «طول عرض» في أسطر، نسخ الشباك السابق، حذف الصفوف الفارغة، استعادة شباك محذوف.
- **ألوان وثيمات وحجم خط** قابلة للتغيير.

## طريقة الاستخدام

1. **النوع:** اختر نوع الشباك (أو مشروعاً محفوظاً، أو استورد ملف Excel).
2. **القياسات:** أدخل لكل شباك الطول والعرض (وعدد القطع إن لزم). إن لم يكن أحد القياسين جاهزاً فاتركه مؤجلاً (انظر [الخانات المؤجلة](#الخانات-المؤجلة)).
3. **النتائج:** راجع المقاسات المحسوبة كبطاقات أو جدول، ثم اضغط **حفظ ومشاركة**، واكتب اسم المشروع إن أردت، واختر PDF أو إكسل.

## أنواع الشبابيك والمعادلات

جميع الأبعاد بالسنتيمتر في المعادلات أدناه (التطبيق يحوّل الوحدة تلقائياً). نرمز بـ **L** للطول الأصلي وبـ **W** للعرض الأصلي.

**القيم الأساسية**

| القيمة | المعادلة |
| :--- | :--- |
| جنب الحلق | `L − 29.5` في النوعين الأول والثاني، و`L` نفسه في النوعين الثالث والرابع |
| أرضية الحلق | `W − 2.6` في كل الأنواع |
| مساحة الشباك | `(L + 10) × (W + 10)` في كل الأنواع |

**القطع حسب النوع**

| القطعة | شباك 3 مجاري نظامي | شباك 2.5 نظامي | واجهات 2.5 بدون صندوق | شباك 3 مجاري بدون صندوق |
| :--- | :--- | :--- | :--- | :--- |
| زرفيل سكين | `جنب الحلق − 7.8` | `جنب الحلق − 7.5` | `جنب الحلق − 7.8` | `جنب الحلق − 7.8` |
| أرضية درفة | `(W + 2) / 2` | `(أرضية الحلق − 0.2) / 2` | `(W + 2) / 2` | `(W + 2) / 2` |
| منخل (طول / عرض) | زرفيل سكين / أرضية درفة | زرفيل سكين / أرضية درفة | زرفيل سكين / أرضية درفة | زرفيل سكين / أرضية درفة |
| زجاج (طول) | `زرفيل سكين − 9.3` | `زرفيل سكين − 9.3` | `زرفيل سكين − 9.3` | `زرفيل سكين − 9.3` |
| زجاج (عرض) | `أرضية درفة − 7.8` | `أرضية درفة − 5.8` | `أرضية درفة − 7.8` | `أرضية درفة − 7.8` |
| مساحة الزجاج | طول الزجاج × عرضه | طول الزجاج × عرضه | طول الزجاج × عرضه | طول الزجاج × عرضه |
| حرف F | `جنب الحلق − 5.5` | غير موجود | `جنب الحلق − 5.5` | `جنب الحلق − 5.5` |
| حرف U | `جنب الحلق + 6.5` | `جنب الحلق + 6.5` | غير موجود | غير موجود |
| صندوق (طول / عرض) | `29.5` / `W` | `29.5` / `W` | غير موجود | غير موجود |
| عامود | `W − 9.5` | `W − 9.5` | غير موجود | غير موجود |
| كشفة (طول / عرض) | `L + 9.2` / `W + 9.2` | `L + 9.2` / `W + 9.2` | `L + 9.2` / `W + 9.2` | غير موجود |
| حصيرة (طول / عرض) | `جنب الحلق + 10` / `W − 11.5` | `جنب الحلق + 10` / `W − 11.5` | غير موجود | غير موجود |

القطع غير الموجودة في النوع المختار تُخفى كلياً من البطاقات والجدول والملفات المُصدَّرة.

**ترتيب القطع في العرض والتصدير:** حلق ← زرفيل سكين ← أرضية درفة ← منخل ← زجاج ← F ← U ← صندوق ← عامود ← كشفة ← حصيرة. القطع ذات البعدين (حلق، منخل، زجاج، صندوق، كشفة، حصيرة) تظهر كخانة رئيسية تتفرع إلى «طول» و«عرض». ومساحة الشباك تُعرض مستقلة عن قائمة التقطيع.

المرجع الكامل للمعادلات في الملف `مرجع معادلات تصنيع الشبابيك (محدّث) (2).md`، والمعادلات مبرمجة في `src/engine/calc.ts`.

## الحفظ والتصدير وتسمية الملفات

من زر **حفظ ومشاركة** في صفحة النتائج:

| الخيار | الوظيفة |
| :--- | :--- |
| 📄 حفظ PDF / 📤 مشاركة PDF | ملف PDF نصي خفيف بخط عربي مضمّن |
| 📊 حفظ إكسل / 📤 مشاركة إكسل | ملف Excel يحوي النتائج والإعدادات، ويمكن استيراده لاحقاً |
| خيارات أخرى | نسخ للإكسل، إرسال النتائج كنص، ملف CSV |

**مجلد المشروع واسم الملف**

لكل مشروع **مجلد خاص** داخل «حاسبة الشبابيك»، ويحمل الاسم نفسه الملفاتُ التي بداخله:

- إن كتبت اسم مشروع: المجلد `اسم المشروع_التاريخ`، مثل `فيلا أبو أحمد_2026-11-24`، وبداخله `فيلا أبو أحمد_2026-11-24.pdf` و`فيلا أبو أحمد_2026-11-24.xlsx`
- إن لم تكتب اسماً: المجلد `نوع الشباك_التاريخ`، مثل `شباك 3 مجاري نظامي_2026-11-24`

ملفات PDF وإكسل وCSV للمشروع نفسه في اليوم نفسه تُحفظ معاً في مجلد واحد. أما النسخة الاحتياطية (JSON) فتُحفظ مباشرة في «حاسبة الشبابيك».

**مكان الحفظ**

- **على الأندرويد:** `التنزيلات / حاسبة الشبابيك / <مجلد المشروع>`. بعد الحفظ يظهر شريط أخضر فيه زر لفتح الملف، وتظهر رسالة تأكيد في أعلى الشاشة تذكر المجلد.
- **في المتصفح:** يُنزَّل الملف إلى مجلد التنزيلات في المتصفح، ولا يمكن للتطبيق إنشاء مجلدات فرعية هناك، فيبقى اسم الملف هو الاسم المذكور أعلاه.

## الخانات المؤجلة

إذا لم يكن الطول أو العرض جاهزاً لشباك ما، فعلّمه كمؤجّل. تظهر الخانات المعتمدة عليه في التطبيق بعلامة ⏳، ثم تعبّئها يدوياً لاحقاً.

في ملف **PDF** تبقى هذه الخانات **فارغة تماماً**، ولا تُكتب فيها أي علامة، لتملأها بالقلم أو بعد الطباعة.

## التشغيل على الحاسوب

المطلوب: **Node.js 22** (أو Bun).

```bash
npm install --legacy-peer-deps
npm run dev        # يعمل على http://localhost:3000
npm run build      # ينتج مجلد dist (ملف HTML واحد)
npm run lint       # فحص TypeScript
```

لا يحتاج التطبيق إلى مفتاح API أو خادم. كل الحسابات وحفظ المشاريع تتم داخل المتصفح، والمشاريع والإعدادات تُخزَّن في `localStorage`.

## بناء تطبيق الأندرويد APK

يبني ملف `.github/workflows/build-apk.yml` تطبيق أندرويد باستخدام **Capacitor 7**:

1. يعمل عند كل **push** إلى `main` أو `master`، ويمكن تشغيله يدوياً من تبويب **Actions**.
2. يبني الواجهة (`npm run build`) ثم يولّد مشروع أندرويد.
3. يُنشئ إضافة أصلية اسمها `SaveFile` تحفظ الملفات في «التنزيلات / حاسبة الشبابيك» (وفي مجلد فرعي لكل مشروع) وتفتحها.
4. يولّد أيقونة التطبيق من `public/app-icon.png`.
5. يبني نسخة **Debug APK**.

**للحصول على الملف:** افتح تبويب **Actions**، اختر آخر تشغيل ناجح، ونزّل `measure-calc-apk`. وإن نجح النشر ففي **Releases** أيضاً.

## التعديلات في هذه النسخة

1. **رسالة الحفظ:** صارت تظهر في **أعلى** الشاشة بدل الأسفل، فلا تغطي شريط فتح الملف.
2. **ملف PDF:** الخانات المؤجلة تُترك **فارغة** بدل علامة «—».
3. **مجلد الحفظ:** صار «التنزيلات / **حاسبة الشبابيك**» بدل «حاسبة القياسات».
4. **مجلد لكل مشروع:** يُنشأ مجلد باسم المشروع والتاريخ داخل «حاسبة الشبابيك»، وعند غياب الاسم: نوع الشباك والتاريخ. وتحمل الملفات بداخله الاسم نفسه.

## ملاحظات للمطوّر

- **بقايا قالب AI Studio:** الحزمتان `@google/genai` و`express` والملف `.env.example` موجودة في المشروع، لكن الشيفرة في `src/` لا تستخدمها، ولا يلزم أي مفتاح Gemini.
- **اسم التطبيق على الهاتف** ما زال «حاسبة القياسات» (من `capacitor.config.json` داخل ملف الـ workflow). غيّر `appName` هناك إن أردت اسماً آخر.
- **الملفات القديمة:** ما حُفظ سابقاً في مجلد «حاسبة القياسات» يبقى فيه ولا ينتقل تلقائياً.
- **`public/window-calc.html`** نسخة جاهزة من التطبيق في ملف واحد، يقدّمها خادم التطوير على `/window-calc.html`، ولا تدخل في بناء الـ APK عندما يوجد `src/`.
- التوقيع الخاص بالمطوّر مضمّن في التطبيق (انظر `SIG_NAME` في `src/engine/calc.ts`).
